When to start a fresh session: long chats with a coding agent

Every session has a moment where starting over would be faster than carrying on. Here's how to spot it, and what the vendor docs say about your options.

By Team Cartographer · October 21st 2026 · 4 minute read

There's a particular feeling about two hours into a long session. The conversation is huge. Early decisions are buried. The agent's answers have gone slightly off, and you can't say exactly when. You keep typing because stopping feels like losing everything.

We've been there, and we think the feeling deserves a straight look. What follows leans on one vendor's own documentation, Anthropic's for Claude Code, because it's the clearest we found on the subject. Other tools may work differently, so check your own tool's docs.

What a long session costs

Anthropic's own post puts it plainly: using context has a slight impact on performance, which is often called context rot.1 They describe context rot as the observation that model performance degrades as context grows.1 Notice the word "slight". It isn't a cliff. It's a slope, and the longer you stay on it, the more it matters.

There's a money side too. The Claude Code cost documentation says the tool sends your full conversation with every request, so a one-line question in a session that has been open all day still draws usage for the whole conversation.2 That page also lists, among the causes of unexpectedly high spend, long sessions that were never cleared.2

The rule of thumb

Anthropic's stated rule is short: when you start a new task, you should also start a new session.1 The cost documentation agrees, advising you to use /clear to start fresh when switching to unrelated work, because stale context wastes tokens on every message that follows.2

The post is honest about the trade. Related tasks may still need some of what's already in the conversation, and starting fresh means the agent has to reread files, which Anthropic calls slower and more expensive.1 So it isn't "always start over." It's "start over when the next job doesn't need the last one."

Three ways out

The same post describes the options, and we like how it frames them as a choice, not a ranking.

  • Clear and brief. Start a new session, usually with a brief you've distilled from what you just learned. Anthropic says it's more work, but the resulting context is what you decided was relevant.1
  • Compact. This asks the model to summarize the conversation so far, then replaces the history with that summary. Anthropic calls it lossy, but notes you didn't have to write anything yourself.1
  • Rewind. When the agent took a wrong turn, Anthropic says rewind is often the better approach to correction, since the messages after that point are dropped from the context.1

Writing your own brief is the interesting one. It forces the question the compaction skips: what did we actually learn? The answer is usually three or four sentences. Which files matter, what we ruled out, what the next step is.

Signs it's time

The docs give a rule about tasks. They don't give a number we can quote for "too long", so we won't invent one. In our own experience the signals are human ones. You're repeating yourself. You're correcting something you already corrected. You can't summarize where things stand without scrolling. When we notice two of those, we stop and write the brief. It costs a few minutes, and it usually saves more than that.

The brief is also a small act of honesty. If you can't write it, you don't yet know what the session achieved, and that's worth finding out before you build more on top of it.

Where session history fits

Starting fresh doesn't have to mean losing the thread. Cartographer reads the session file your agent already keeps and turns it into a map of how the project was built, as how it works explains. Before you clear, a map of the session so far can show you the decisions and dead ends worth carrying into your brief.

A small test

Next time a session feels heavy, pause and write the brief anyway: what we decided, what we ruled out, what comes next. Then choose. If the brief fits in a few lines, start fresh with it. If it sprawls, the session was telling you something.
