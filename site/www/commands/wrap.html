Commands

cartographer wrap

Write the brief for a session.

Usage

cartographer wrap [--session id] [--force] [--run]

Digests a session's transcript into a timeline with a reading of every prompt, then writes the brief the agent uses to write the map. This is what the /wrap command in Claude Code runs before Claude does the writing.

Options

  • --session id wraps an older session instead of the latest one.
  • --force redoes a session that already has a brief.
  • --run also maps it with the agent's headless CLI, with no human in the loop.

When to use it

At the end of a session, or from a script that maps sessions automatically.

Windows: the same command works in PowerShell, cmd and Git Bash. If cartographer is not found, open a new terminal so the PATH change takes effect. Every command is listed on the commands page.
