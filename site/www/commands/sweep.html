Commands

cartographer sweep

Map every session that has gone quiet and is not mapped yet.

Usage

cartographer sweep [--dry]

Finds sessions that have stopped and have no map, and maps them. It exists for agents that have no session-end event, and it is meant to be run on a schedule.

Options

  • --dry lists what would be mapped without mapping anything.

When to use it

From a scheduled job, when you want everything mapped without remembering to wrap.

Windows: the same command works in PowerShell, cmd and Git Bash. If cartographer is not found, open a new terminal so the PATH change takes effect. Every command is listed on the commands page.
