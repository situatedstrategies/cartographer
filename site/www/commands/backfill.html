Commands

cartographer backfill

Briefs, or maps, for every past session of a repo.

Usage

cartographer backfill --cwd repo [--run]

Prepares a brief for every session Claude Code still has on disk for a repo, so sessions from before you installed Cartographer can be mapped. This is what /cartographer-setup backfill runs.

Options

  • --cwd repo points at the repository whose sessions you want.
  • --run maps them headlessly instead of only writing briefs.

When to use it

Once, after installing, to bring the history in. Retrospective maps read a little flatter than live ones, because nobody was there to be corrected.

Windows: the same command works in PowerShell, cmd and Git Bash. If cartographer is not found, open a new terminal so the PATH change takes effect. Every command is listed on the commands page.
