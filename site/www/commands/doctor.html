Commands

cartographer doctor

Version, home folder, mode, agents found, headless runners.

Usage

cartographer doctor

Prints what Cartographer can see: its version, the home folder, whether wrapping is manual or automatic, which agents were found and how many sessions each has, and which headless runners are available.

When to use it

First thing to run when something does not work, and the output to paste when you write to support.

Windows: the same command works in PowerShell, cmd and Git Bash. If cartographer is not found, open a new terminal so the PATH change takes effect. Every command is listed on the commands page.
