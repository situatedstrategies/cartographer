Commands

cartographer goal

Declare what done means for the current version.

Usage

cartographer goal "what done means"

Records, in your words, what the current version of the repo is supposed to achieve. It is the source of truth for every map and for the appraisal: every session map is judged against it, and complete reads the result back against it.

Options

  • Takes one quoted sentence. Run it in the repo the version belongs to.

When to use it

Before you start a version, ideally. It is optional, and /complete will ask for it later if you never declared one.

Windows: the same command works in PowerShell, cmd and Git Bash. If cartographer is not found, open a new terminal so the PATH change takes effect. Every command is listed on the commands page.
