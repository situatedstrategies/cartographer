Commands

cartographer serve

The dashboard in your browser, this machine only.

Usage

cartographer serve --open

Opens the dashboard: your profile, recent sessions with a Map this session button, projects, maps, outcomes and completion. It binds to 127.0.0.1 and refuses requests from anywhere else, so nothing is reachable from the network.

Options

  • --open opens your browser on the dashboard as soon as it is up.

When to use it

When you want to see what has been mapped, pick a session to map by hand, or read a replay without remembering a project name.

Windows: the same command works in PowerShell, cmd and Git Bash. If cartographer is not found, open a new terminal so the PATH change takes effect. Every command is listed on the commands page.
