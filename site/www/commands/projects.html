Commands

cartographer projects

Every project with its sessions, versions, outcomes and appraisals.

Usage

cartographer projects

Lists everything Cartographer knows: each project, its sessions, its declared versions and goals, and the appraisals that closed them.

When to use it

An inventory, when you want to see the shape of the work across repos.

Windows: the same command works in PowerShell, cmd and Git Bash. If cartographer is not found, open a new terminal so the PATH change takes effect. Every command is listed on the commands page.
