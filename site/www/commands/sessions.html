Commands

cartographer sessions

Every session found for every installed agent.

Usage

cartographer sessions --all

Lists the sessions Cartographer can see. A tick marks the ones already mapped, so you can see at a glance what is still unmapped.

Options

  • --all lists every agent's sessions, not only the current repo's.

When to use it

Before a backfill, or when you want to map one specific older session and need its id.

Windows: the same command works in PowerShell, cmd and Git Bash. If cartographer is not found, open a new terminal so the PATH change takes effect. Every command is listed on the commands page.
