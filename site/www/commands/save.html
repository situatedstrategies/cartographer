Commands

cartographer save

Validate, redact, file and render a map or an appraisal.

Usage

cartographer save file.json [--check]

Takes a map or appraisal file the agent has written, validates it against the rules, redacts secrets, files it under the project, and renders the replay. This is what Claude runs at the end of /wrap.

Options

  • --check only validates, and writes nothing.

When to use it

You rarely run it yourself. It is the last step of every wrap and every completion.

Windows: the same command works in PowerShell, cmd and Git Bash. If cartographer is not found, open a new terminal so the PATH change takes effect. Every command is listed on the commands page.
