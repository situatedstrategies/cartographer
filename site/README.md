# codecartographer.dev

Everything for the domain that is not the CLI itself.

| Folder | What |
|---|---|
| `www/` | The public site: `index.html` (install, instructions, commands), `install.sh` (the one-line installer). `demo.html` and `cartographer.tar.gz` are generated by `build.sh`, not committed. |
| `build.sh` | Copies the demo replay in and packs the checkout as the tarball the installer downloads. |
| `email-worker/` | Cloudflare Email Worker that tags mail for support@ and mapit@ and forwards it. Its own README has the routing steps. |

## Deploy the site (Cloudflare Pages)

1. Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git → this repository, production branch `main`.
2. Build command: `sh site/build.sh`. Build output directory: `site/www`. No framework preset, no environment variables.
3. Custom domain: `codecartographer.dev` (Pages → Custom domains). Cloudflare adds the DNS record.
4. Check `https://codecartographer.dev/install.sh` and `https://codecartographer.dev/cartographer.tar.gz` both download, then run the one-liner on a clean machine.

Every push to `main` rebuilds the site and the tarball, so the installer always ships the current `main`.

## Preview locally

```bash
sh site/build.sh && python3 -m http.server -d site/www 8080
```

Then open http://localhost:8080/. To test the installer against the local build without touching your real setup:

```bash
HOME=$(mktemp -d) CARTOGRAPHER_TARBALL=site/www/cartographer.tar.gz sh site/www/install.sh
```
